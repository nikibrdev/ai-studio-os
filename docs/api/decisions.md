# API: Decisions

## Назначение

Чтение того, что ждёт решения человека: задачи, стоящие в контрольных точках (`TaskProjection.ListAwaitingDecision`, `internal/application`). Нормативное определение контрольной точки — [workflow.md](../architecture/workflow.md#контрольные-точки-человека).

## Содержание

### Общие сведения

- Версия: v1
- Аутентификация: не требуется ([ADR-012](../adr/ADR-012-identity-and-auth.md))
- Базовый путь: `/decisions` — **не вложен под проект**, в отличие от операций задач: вопрос, на который отвечает операция, — «что ждёт решения вообще», а не «что ждёт решения в этом проекте». Признак по отдельной задаче доступен в её представлении (`awaitingDecision` в [tasks.md](tasks.md)), поэтому отдельная операция «по проекту» не вводится.

### Контрольные точки

Их две, и они заданы [ADR-007](../adr/ADR-007-pm-qa-executors.md):

| `decision` | Состояние задачи | Что решает человек | Команда, выражающая решение |
| --- | --- | --- | --- |
| `definition-of-ready` | `backlog` | Задача готова к работе | `POST /projects/{projectId}/tasks/{id}/plan` |
| `acceptance` | `testing` | Definition of Done выполнен | `POST /projects/{projectId}/tasks/{id}/complete-testing` |

**Платформа не отличает человека от агента** на этих командах: аутентификации нет (ADR-012), гарантия процессная — подробнее в [workflow.md](../architecture/workflow.md#контрольные-точки-человека).

### Операции

#### Список ожидающих решения

**Назначение:** возвращает задачи, стоящие в контрольных точках, по всем проектам. Порядок детерминирован — сначала по идентификатору проекта, затем по идентификатору задачи.

**Запрос:** `GET /decisions`

**Ответ:** `200 OK`

```json
{
  "decisions": [
    {
      "decision": "definition-of-ready",
      "task": {
        "id": "TASK-001",
        "projectId": "proj-1",
        "state": "backlog",
        "title": "string",
        "type": "string",
        "scope": "string",
        "acceptanceCriteria": ["string", "..."],
        "awaitingDecision": "definition-of-ready",
        "updatedAt": "RFC3339"
      }
    }
  ]
}
```

Пустой список — `200 OK` с `"decisions": []`, а не `404`: отсутствие ожидающих решения — нормальное состояние системы.

**Ошибки:** нет специфичных для операции.

**События:** не публикует (операция чтения).
