# TASK-105: Поднять платформу по документации, закрытие EPIC-014 и v1.0

## Тип

test

## Эпик

[EPIC-014 Стабилизация и релиз](../../docs/roadmap/EPIC-014-stabilization-release.md)

## Цель

Проверить документацию единственным способом, которым её можно проверить: поднять платформу с нуля, следуя **только** написанному, и убедиться, что инструкций достаточно. Закрыть эпик и веху v1.0.

## Контекст

Все живые проверки прошлых эпиков делались с уже накопленным знанием: какие переменные окружения нужны, в каком порядке запускать, что должно быть собрано. Читатель этого знания не имеет — у него есть только README.

Опыт эпиков: каждая живая проверка находила то, чего не видели тесты (восемь дефектов за четыре эпика). Здесь проверяется не код, а **достаточность инструкций** — и найденное чинится в документации, а не обходится знанием, которого у читателя нет.

## Scope

### Входит

- Поднять платформу с нуля по README корня и README модулей: зависимости, PostgreSQL, образ песочницы, `apps/api`, `apps/orchestrator`, `apps/dashboard`.
- Фиксировать **каждый** момент, где пришлось воспользоваться знанием не из документации (переменная окружения, порядок запуска, предварительная сборка) — это и есть дефекты документации.
- Исправить найденное в документации; повторить проверку, если правки существенны.
- Обновление критериев эпика, ROADMAP (v1.0 — завершено), PROJECT_MANIFEST, PROJECT_HEALTH.
- Итог по вехе v1.0: что достигнуто и что осознанно осталось за её пределами.

### Не входит

- **Публикация тега `v1.0.0`** — решение владельца проекта (см. TASK-104).
- Исправление кода: если инструкция не работает из-за кода, а не из-за текста, — зафиксировать как отдельную задачу.
- Открытые вопросы предыдущих эпиков.

## Критерии приёмки

- [ ] Платформа поднята с нуля по документации; каждый случай «пришлось знать сверх написанного» зафиксирован.
- [ ] Найденные пробелы документации исправлены.
- [ ] EPIC-014 закрыт; веха **v1.0 закрыта** в ROADMAP с честным перечнем достигнутого и не сделанного.

- [ ] В отчёте явно указано, что публикация релиза остаётся за владельцем.
- [ ] `make verify` — чисто; весь набор `-tags integration` — зелёный.
